# AFTERGLOW — Music & Arts Festival Website

A responsive, front-end event management website concept built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive festival landing page for mobile, tablet and desktop
- Artist/event cards with search and category filters
- Event detail pop-ups
- Registration form with HTML and JavaScript validation
- Registration confirmation and Local Storage persistence
- Live countdown to the festival date
- Dark/light theme toggle (preference saved in Local Storage)
- Mobile navigation, hover effects and CSS animations

## Run locally
1. Download and extract the project.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with the Live Server extension.

No backend or build tools are required.

## Registration data
Successful demo registrations are saved in the browser's Local Storage under `afterglowRegistrations`. This is a front-end demonstration, not a real ticketing or payment system. Data stays in the browser/device where it was submitted.

## Deployment
- **GitHub Pages:** Push the files to a GitHub repository, then enable Pages in Settings → Pages.
- **Netlify:** Drag the extracted project folder into Netlify Drop, or connect the GitHub repository.
- **Vercel:** Import the GitHub repository and deploy as a static site.

## Customisation
Edit event details in the `events` object in `script.js`, event cards in `index.html`, and colours/typography in `style.css`.

## Note
AFTERGLOW, the festival schedule, artists, venue details and ticket prices are fictional sample content created for a student project.
